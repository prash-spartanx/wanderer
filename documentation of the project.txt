// current events of every service and short description of what it means
-----------------------------------------------------------------------------
speech-service
-----------------------------------------------------------------------------
wake_word_detected-> // speech service is responsible for detecting wake word and sending this event
person_identified ->                // speech service fires this event when it succesfully transcribes the persons name when the brain command sends "identify" command with a text
transcription_ready -> // speech service sends this event a minute after wakeword detected command. for a minute(or configured time) the speech service keeps mic open and transcribe every speech to text and fires this command along with transcribed text
----------------------------------------------------------------------------
navigation-service
----------------------------------------------------------------------------
obstacle_detected -> this is the only event the navigation service fires when there object closer than configured threshold

----------------------------------------------------------------------------
vision-service
----------------------------------------------------------------------------
unknown_person_detected -> fires this even when it scans after brain commands and finds the person is not saved in db.
person_detected-> when it scans and finds a matching profile in db , returns the name of the person in text
object_detected-> when thers no face but an object calls an open image processing llm to detect the object and returns it as text
saved_face -> fires this event after successfully saves the image matrix of the event in db with the name provided by the brain command'saveface'
'no_face_detected -> when no face or object is detected

**navigation**
Stop -> stop the motors temperorily
start -> resume the motors 
left -> make a left turn
right -> make a right turn 

**speech**
speak ->  say the text in the command 
identify -> say the text In the command and turn on mic to process speech

**vision**
scan -> called whenever the navigation services detects something and sends object detected event , dtects wheather the object is person or an obstacle, uses saved profiles to retrieved people name and if not present returns unknown_person_detected event and if obstacle then sends object_detected with the object name
saveFace -> called after unknown_person_detected to save the profile of new face with name provided by speech service after identify command was given

my expectation from the project and basic design
-----------------------------------------------------------------------------
I am working on software which basically gives a physical robot a brain it follows a microservice architecture with 4 services brain,vision,speech and navigation,who only communicate through kafka. each service acts as dumb and only has sole purpose. 
so I want my robot to wake up whenever I say the wake word which will be configured In speech service, I may give it any command but it will be one command . lets say I say it to wander it should check its current state and intent and act accordingly. everytime it detects any obstacle it has to stop which will be handled by navigation service, but it should do the same till it is speaking or listening for the command from the user.
